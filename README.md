## 📚 Simple Nav Bar (Horizontal & Vertical) – HTML + CSS

This project demonstrates how to build **simple horizontal and vertical navigation bars** using only **HTML and CSS**. It’s perfect for beginners learning layout design and navigation structures.

### 🌟 Features:
- ✅ Horizontal Navigation Bar  
- ✅ Vertical Navigation Bar  
- 💡 Simple and clean UI  
- 💻 Responsive design (can be made mobile-friendly)  
- 🔤 Customizable menu items

### 🛠️ Technologies Used:
- HTML5
- CSS3

### 📚 Purpose:
This repo is created for educational purposes and to help beginners understand how to create different types of navigation menus without JavaScript.

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Simple-Nav-Bar.git
   ```
2. Open the `index.html` file in your browser.
3. You’ll find examples for both horizontal and vertical nav bars in the code.
